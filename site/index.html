How it works

Name it once. Use it everywhere.

Your aliases live in one small file. aka turns it into the right syntax for each shell and loads it for you, so there's no profile editing and no restart.

Add an alias

Any command, with an optional note or tag.

$ aka add glog "git log --oneline --graph" ✓ Added glog → git log --oneline --graph

Use it right away

In the terminal you're in, and every new one.

$ glog * 4c54258 Add search API * d1a583c Fix token refresh

Let it suggest more

It reads your history locally and finds what's worth shortening.

$ aka suggest # USED COMMAND 1 14 docker compose up -d --build
Features

Small tool. Careful about the details.

Every shell, one file

Write an alias once and it works in all of them, on macOS, Linux and Windows. Aliases that take arguments work too.

bashzshfishPowerShell
$ aka add mkcd 'mkdir -p "$1" && cd "$1"'

Asks before replacing

Re-using a name shows both commands, and cancel is the default.

gs already exists: current git status new git status -sb [r]eplace / [n]ew name / [c]ancel

Undo anything

Every change is backed up. Removed aliases go to a trash you can restore from.

$ aka undo ✓ Undid "remove gs".

Safety checks

Warns when a name hides a real command, blocks aliases that loop, and flags risky ones like rm -rf.

Tab completion

Alias names complete with their descriptions, and gco <Tab> still completes your branches.

For AI agents too

Fewer characters. Fewer tokens.

Coding agents run the same long commands over and over. Tell yours about your aliases and it writes the short version instead: less to generate, less noise in the context.

This works when your agent's shell loads your shell config and the agent knows the aliases exist, so list them in CLAUDE.md or AGENTS.md. aka list --plain prints them, one per line.

Install

Thirty seconds, then done.

Each script downloads the right build for your machine and checks its checksum before installing. Then run aka setup once and open a new terminal.

macOS & Linux

Installs to ~/.local/bin.

curl -fsSL https://github.com/boltbench/aka/releases/latest/download/install.sh | sh

Windows

In PowerShell. Adds itself to your PATH.

irm https://github.com/boltbench/aka/releases/latest/download/install.ps1 | iex

From source

With a recent Rust toolchain.

cargo install --git https://github.com/boltbench/aka

Stop retyping. Start naming.

$ aka add glog "git log --oneline --graph --decorate --all -6"
