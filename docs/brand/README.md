# Brand assets

| File | Use |
|---|---|
| `aka-icon.svg` | The app icon, with rounded corners |
| `aka-avatar.svg` / `.png` | Square version for avatars (GitHub rounds the corners itself) |
| `aka-wordmark-dark.svg` | The "a.k.a" wordmark for dark backgrounds |
| `aka-wordmark-light.svg` | The same for light backgrounds |
| `aka-social.svg` / `.png` | 1280x640 image for the repo's social preview |

The letters are drawn from strokes rather than a font, so they look the same everywhere. Colors: ink `#0A0E1C` to indigo `#1C1747`, with the dots going from violet `#C4B5FD` to cyan `#22D3EE`.
